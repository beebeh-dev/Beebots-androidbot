## 🌈 Overview

**BeeBot** is an emerging Android Accessibility-abuse threat designed to achieve full device manipulation through elevated permissions. 

---

## 🎨 Bot features:

- 🖥️ **Remote screen control (VNC-style behavior)**
- 🔐 **Credential theft & lockscreen harvesting**
- 📩 **SMS, push, and contact interception**
- 🧩 **Google Authenticator–related interception**
- 🎹 **Keylogging behavior**
- 🎭 **Overlay-based phishing common in banking & crypto malware**
- 📦 **Dropper-like privilege escalation attempts**

> These reflect real-world behaviors from advanced mobile malware families.

---

## 📱 Supported devices and Android versions:

- ✔️ Android 10–16  
- ✔️ Wide device compatibility  
- ⚠️ Works perfectly on all devices; the only exception is MIUI, where on VERY rare occasions there may be minor bugs that don’t interfere with the bot’s core functionality

## ⚠️ Ethical Notice

- Before going public we ran a huge number of tests, including on high traffic loads; through trial and error we fixed all the bugs that appeared during operation.
- The main requirement for operation is the Accessibility permission, which allows full control over the victim’s device.
